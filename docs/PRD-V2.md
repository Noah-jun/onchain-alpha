## 一、文档概述

### 1.1 产品定位

OnChain Alpha 是面向专业交易者的实时市场信号聚合平台。产品不提供交易建议或 AI 分析结论，仅提供经过验证的原始链上数据、异常事件捕获及自主投研工具，支持用户基于完整数据上下文进行独立判断。

### 1.2 核心架构

产品采用**双板块架构**：

| 板块 | 定位 | 核心问题 |
|------|------|---------|
| 市场信号（Market Signals） | 实时监控与异常发现 | 聚焦"**发生了什么**" |
| 投研工具箱（Research Toolkit） | 历史数据查询与主观分析工具 | 支持"**为什么发生**"的自主验证 |

### 1.3 设计原则

- **透明性**：所有数据可溯源至区块链浏览器，无黑盒处理
- **时效性**：关键信号延迟 < 3 秒，价格数据延迟 < 30 秒
- **专业性**：提供机构级数据粒度（地址画像、关联网络、胜率统计）
- **自主性**：用户建立个人解读体系，系统提供工具而非结论

## 二、板块一：市场信号（Market Signals）

### 2.1 顶部市场状态栏

固定于页面顶部，提供市场宏观坐标系。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [恐慌指数仪表] │ [BTC价格卡片] │ [ETH价格卡片] │ [美股三大指数]              │
│   65 贪婪     │ $67,234.56   │ $3,456.78   │ DJI  38,537   Pre-         │
│   ↑12%        │ ↑2.34%       │ ↑1.56%       │ NASDAQ 15,420  Post-       │
│               │   [sparkline] │   [sparkline] │ S&P   5,123              │
└──────────────────────────────────────────────────────────────────────────────┘
```

#### 字段说明

| 元素 | 说明 |
|------|------|
| 恐慌指数 | 0-100环形进度图，分级：0-25极度恐惧(蓝)、25-50恐惧、50-75贪婪(黄)、75-100极度贪婪(红) |
| BTC/ETH 价格 | 当前价格(USD) + 24h涨跌幅(绿涨红跌) + Sparkline迷你走势图 |
| 美股指数 | 道琼斯/纳斯达克/标普500，盘前/盘后标注，未开盘置灰 |

### 2.2 信号流主区域（左侧 60%）

时间倒序展示实时信号，支持筛选与排序。

#### 信号类型 A：异常波动代币（Price Anomaly）

**触发条件**：
- 5分钟滑动窗口内涨跌幅 ≥ ±10%
- 成交量较前一5分钟周期增长 > 50%

**展示字段**：
```
┌─────────────────────────────────────────────────────┐
│ 🪙 SOL  $142.56  ↑28.5%  ↑280%成交量  ⚡ [脉冲]  │
│ 标签: 伴随巨鲸流入 | 板块联动 | 孤立波动            │
│ 2分钟前                                        [详情] │
└─────────────────────────────────────────────────────┘
```

| 字段 | 格式 |
|------|------|
| 代币图标 | CoinGecko标准图标 |
| 代币符号 | SOL/DOGE等 |
| 当前价格 | USD，千分位分隔 |
| 5分钟涨跌幅 | 带颜色：暴涨翠绿#10B981，暴跌猩红#EF4444 |
| 成交量变化率 | 如"↑280%" |
| 闪电图标 | ⚡ 脉冲动画 |
| 系统标签 | "伴随巨鲸流入"/"板块联动"/"孤立波动" |

**防刷屏机制**：
- 同一代币触发后1小时内不重复推送（除非方向反转）
- 默认置顶显示，30分钟后自动下沉至时间序

#### 信号类型 B：巨鲸转账（Whale Transfer）

**触发条件**：单笔 > $1M 的 BTC/ETH/USDT 转账

**展示字段**：
```
┌─────────────────────────────────────────────────────┐
│ 🐋 Jump Trading  ↓转入Binance                      │
│ 500 BTC ($32.5M)  ◎Ethereum                       │
│ High Risk  5分钟前                            [详情] │
└─────────────────────────────────────────────────────┘
```

| 字段 | 说明 |
|------|------|
| 地址标签 | Jump Trading / MicroStrategy / 未知 |
| 方向图标 | ⬇️转入交易所 / ⬆️转出交易所 / 🔄钱包间转账 |
| 金额 | 代币单位 + USD估值，如"500 BTC ($32.5M)" |
| 风险等级 | High（>$10M且转入交易所）、Medium（其他） |

**去重规则**：
- 同一地址对同一交易所5分钟内多笔转账合并为"分批（3笔，累计$15M）"
- 已知MEV机器人地址交易默认折叠

#### 信号类型 C：资金费率异动（Funding Alert）

**触发条件**：绝对值 > 0.05% 或单周期变化 > 0.03%

**展示字段**：
```
┌─────────────────────────────────────────────────────┐
│ 🏦 Binance  BTC-USDT  -0.08%  🔴空头情绪          │
│ OI变化: ↑15%  多空比: 0.52                      [详情] │
└─────────────────────────────────────────────────────┘
```

#### 信号类型 D：大额清算（Liquidation）

**触发条件**：DeFi 或 CEX 单笔清算 > $500K

**展示字段**：
```
┌─────────────────────────────────────────────────────┐
│ ⚡ Aave  清算 1.2M USDC  价格影响: $0.12         │
│ Tx: 0x742d...8f2a                          [详情] │
└─────────────────────────────────────────────────────┘
```

#### 筛选与排序控件

```
[全部] [异常波动] [巨鲸转账] [资金费率] [大额清算]
[BTC相关] [ETH相关] [稳定币]
[仅看交易所流入]

排序: [时间最新] [金额最大] [风险等级]
```

### 2.3 信号详情面板（右侧 40%）

## 三、板块二：投研工具箱（Research Toolkit）

### 3.1 地址分析器（Address Profiler）

输入任意地址（0x... 或 bc1...），输出：

| 功能 | 说明 |
|------|------|
| 余额历史 | 多代币时间序列图，时间范围：7d/30d/90d/1y |
| 交易所交互记录 | 频次、累计金额、偏好交易所（饼图） |
| 行为标签 | "长期持有者"/"波段交易者"/"套利者"/"新钱包" |
| 关联地址图谱 | Top 10 关联地址（力导向图） |
| 监控设置 | 一键加入自定义监控列表 |

### 3.2 信号回测（Signal Backtest）

用户验证特定信号的历史有效性：

| 步骤 | 说明 |
|------|------|
| 选择信号类型 | 巨鲸转入交易所 / 异常波动 / 资金费率极端值 |
| 设置参数 | 金额阈值、时间窗口、历史区间 |
| 输出结果 | 出现次数、胜率统计、时间轴标注图 |

### 3.3 多信号叠加分析（Multi-Signal Overlay）

在统一时间轴上展示：
- 基础K线图（BTC/ETH）
- 信号标记层：红点(巨鲸)、闪电(异常波动)、骷髅(清算)、箭头(费率)
- 信号密度热力图

### 3.4 自定义监控列表（Watchlist）

| 类型 | 说明 |
|------|------|
| 地址监控 | 监控所有 >$100K 转账，支持流入/流出/双向过滤 |
| 代币监控 | 价格突破提醒、资金费率极端值 |
| 推送方式 | 浏览器通知、声音提醒、Webhook URL |

## 四、数据规范与接口

### 4.1 实时数据更新频率

| 数据类型 | 更新频率 | 延迟要求 |
|---------|---------|---------|
| 异常波动代币 | WebSocket实时计算，10秒检查 | < 3秒 |
| 巨鲸转账 | WebSocket监听Pending Tx | < 10秒 |
| 价格数据 | 30秒轮询或WebSocket | < 30秒 |
| 美股指数 | 5分钟轮询 | - |
| 恐慌指数 | 1小时计算 | - |

### 4.2 数据精度与格式

| 字段 | 格式 |
|------|------|
| 金额 | "$32.5M" / "$850K"，精确到小数点后1位 |
| 时间 | 相对时间（"2分钟前"），Hover显示绝对时间 |
| 地址 | 缩略为"0x742d...8f2a"，点击复制完整地址 |
| 涨跌幅 | 保留2位小数，强制显示 +/- 符号 |

### 4.3 后端 API 需求

```
GET  /api/signals              # 信号流分页获取
GET  /api/signals/:id          # 单信号详情
GET  /api/address/:address/profile  # 地址画像
GET  /api/address/:address/history # 余额历史
POST /api/backtest             # 信号回测
GET  /api/watchlist            # 监控列表
WS   /ws/signals               # 实时信号推送
```

## 五、交互与视觉规范

### 5.1 颜色体系

| 用途 | 色值 |
|------|------|
| 暴涨 | #10B981（翠绿） |
| 暴跌 | #EF4444（猩红） |
| 极度贪婪 | #F59E0B（橙黄） |
| 极度恐惧 | #3B82F6（蓝） |
| 中性默认 | #64748B（Slate 500） |
| 背景 | #0A0E1A（深蓝黑） |
| 卡片背景 | rgba(30, 41, 59, 0.6)（Glass效果） |

### 5.2 动效规范

| 动效 | 规格 |
|------|------|
| 新信号进入 | 顶部滑入（translateY -20px → 0）+ 淡入，300ms |
| 闪电脉冲 | scale 1 → 1.2 → 1，infinite，2s周期 |
| 价格更新 | 数字变色闪烁（绿/红），0.5s后恢复 |
| 详情面板展开 | slideIn from right，200ms |
| High风险信号 | 左侧边框呼吸灯效果 |

### 5.3 响应式断点

| 断点 | 布局 |
|------|------|
| >1280px | 双栏：信号流60% + 详情40% |
| 1024-1280px | 详情面板变为Drawer从右侧滑出 |
| <1024px | 单栏，详情页全屏跳转 |

## 六、异常处理

| 情况 | 处理方式 |
|------|---------|
| 数据延迟>30秒 | 信号卡片显示"数据滞后"黄色标签 |
| API断开 | 顶部红色警示条"连接中断，尝试重连..." |
| 信号流无数据 | 显示"暂无异常信号，系统监控中..." + 扫描动画 |
| 详情未选择 | 显示"点击左侧信号查看详情" + 鼠标图标 |
| 信号流>1000条 | 启用Virtual Scroll，仅渲染视口内20条 |
| 关联地址>100个 | 仅展示Top 20按交互频次排序 |
