## 组件状态汇总

| 组件 | 状态类型 | 视觉表现 |
|------|---------|---------|
| 指标卡片 | Default | 白底 + 数字 + 标签 |
| 指标卡片 | Hover | 浅灰背景 + 显示更新时间 |
| 信号卡片 | Default | 白底卡片 + 左边框色 |
| 信号卡片 | Hover | 阴影加深 + 显示详情按钮 |
| 信号卡片 | Selected | 蓝色边框 + 高亮 |
| AI 气泡 | Loading | 打字机效果 + 逐字显示 |
| AI 气泡 | Error | 红色背景 + 重试按钮 |
| Gauge | Safe (0-30) | 绿色填充 |
| Gauge | Warning (30-70) | 黄色填充 |
| Gauge | Danger (70-100) | 红色填充 |
| 按钮 | Default | 蓝色背景 |
| 按钮 | Hover | 深蓝色 |
| 按钮 | Disabled | 灰色 + 禁用 |
| 输入框 | Focus | 蓝色边框 |
| Toast | Error | 红色 + 错误图标 |
| Toast | Success | 绿色 + ✓ 图标 |
| Toast | Loading | 蓝色 + 转圈 |

## 快捷键汇总

| 快捷键 | 功能 |
|--------|------|
| `Cmd + K` | 打开全局搜索 |
| `Enter` | 发送消息 |
| `Shift + Enter` | 换行 |
| `Esc` | 关闭弹窗/面板 |
| `1` | 跳转 Dashboard |
| `2` | 跳转 Research |
| `3` | 跳转 Risk |
