前Farcaster创始人、Tempo团队成员Dan Romero：Tempo或将在2年内实现去中心化，亚洲市场负责人已就位

Odaily星球日报讯 近日，前链闻创始人刘锋与前 Farcaster 创始人、Tempo 团队成员 Dan Romero 就支付、加密货币及 AI Agent 等话题展开了一系列讨论。其中，Dan Romero 回应了外界及刘锋关注的部分问题，其中重点如下：

1.从理想主义的 socialfi 产品到大企业主导的公链的原因： "加密世界发生了变化，现在有的是稳定币和 crypto（更原生）两种东西 "；Tempo 及 playbook 的目标是： "从支付业务开始，和大型、成熟公司合作，帮助他们开展链上的支付，促进自身业务发展；然后，结合 DeFi 应用，推出最终用户需要的收益型产品"；

2. "Tempo 没有 Meme 币或类似的东西，对于一家保守的银行来说，这是好事。Tempo 还有其他特点：合规性、隐私。对于加密原住民来说，这可能没有那么有趣。对于银行来说，这非常吸引人 "；

3.关于支付的核心用例： "平台型 marketplace 和跨境支付是两个清晰的稳定币使用案例 "；

4.微支付主导的智能体支付值得期待；基于稳定币的微支付将引来春天：智能体之间的支付， "传统支付方式成本太高，无法大规模进行。这种颗粒度和速度的要求只有通过加密货币和流支付才能实现 "；

5. "我非常尊重以太坊在去中心化这一点上所坚持的密码朋克的做法，很喜欢他们这个新的使命，这对世界是好的；但现实是，企业不关心这些，他们关心到底能不能解决实际问题 "； "如果 Tempo 能够吸引 100 万个企业和 10 亿个消费者，对加密货币和以太坊都不是坏事 "；6.Tempo 的去中心化进程：希望两年能实现， "我们可不是一群穿西装的门外汉，我们是真懂；我们知道去中心化多么重要，但同时我们也非常务实，我保证能真正把应用推起来。

6.关于机器支付协议（MPP）与 X402 协议，AI Agent 不关心两者的差异，让他们满意的关键在于无需人类介入；

7.Tempo 亚洲市场负责人已就位，将在新加坡开展工作。

Stripe官方发布MPP机器支付协议，AI Agent可通过提示词自主完成支付设置及集成

Odaily星球日报讯 Stripe 官方于 X 平台发文表示，现已上线 Machine Payments Protocol（MPP，直译为机器支付协议）新功能，用户仅需向 AI Agent 发送一个 prompt 提示词，即可完成 AI Agent 支付相关的设置和集成。目前已有 @zincdotcom、@agentscoretrust、@ondbai 等公司开始接受来自 AI agents 通过 MPP 和 x402 协议的机器支付。

据悉，该功能大幅降低了 AI Agent 自主支付集成的门槛，从过去需要手动写代码，变成“一句 prompt 即可搞定”。
